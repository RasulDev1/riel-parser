# Консольный парсер Авито с уведомлениями в Telegram

Работает на ПК риелтора через его домашний интернет. Следит за ссылками поиска Авито,
находит новые объявления, отсеивает агентов и дубли, присылает новое в Telegram.

## Быстрый старт (Windows)

Нужен только Python 3.10+ (при установке отметьте «Add python.exe to PATH»).
Библиотеки `httpx` и `curl_cffi` программа ставит сама при первом запуске,
а если нет `config.json`, копирует его из `config.example.json`.

- `test.bat`: пробный прогон, один проход без отправки в Telegram, подробный лог.
- `start.bat`: рабочий режим.

Или из PowerShell / командной строки в папке `cli`:

```bash
python main.py --once --dry-run -v  # пробный прогон
python main.py --test-telegram      # проверить бота
python main.py                      # рабочий режим
```

Сборка `.exe` под Windows: запустите `build_exe.bat`. Получите `dist\AvitoParser.exe`
и рядом `dist\config.json`. `history.db` и `parser.log` появятся там же.

## config.json

| Поле | Что это |
|---|---|
| `telegram_bot_token` | токен бота от @BotFather |
| `rieltor_chat_id` | chat id риелтора (узнать: написать боту @userinfobot) |
| `global_check_interval_seconds` | пауза между проверками ссылок, не меньше 10 с (рекомендуется 45–90) |
| `jitter_seconds` | случайный разброс паузы, ± секунд |
| `notify_on_first_run` | `false`: при первом запуске ссылки текущие объявления только запоминаются, приходят лишь новые |
| `anti_agent.enabled` | включить фильтр «Анти-Агент» |
| `anti_agent.max_active_listings` | больше скольких активных объявлений у продавца считать его агентом (по умолчанию 1) |
| `anti_agent.max_closed_listings` | больше скольких завершённых объявлений считать агентом (по умолчанию 0) |
| `anti_agent.skip_if_unknown` | пропускать объявление, если продавца проверить не удалось |
| `targets_to_watch` | список `{client_name, avito_url}`; ссылку копируйте из браузера после настройки фильтров на Авито |

## Как работает

1. Ссылка из конфига нормализуется: `m.avito.ru` → `www.avito.ru`, сортировка «по дате», первая страница.
2. Страница грузится через `curl_cffi` с TLS-отпечатком Chrome и куками (сначала заход на главную).
3. Объявления берутся из встроенного в страницу JSON-состояния. Если Авито его уберёт, есть запасной разбор HTML.
4. Новые ID проверяются по `history.db`, затем по хешу описания (дубли с перевыложенными объявлениями).
5. «Анти-Агент»: открывается карточка и профиль продавца. Компания/агентство или объявлений больше лимита → пропуск.
   Результат проверки продавца кешируется на 7 дней.
6. Сообщение уходит в Telegram: клиент, заголовок, цена, адрес, 150 символов описания, ссылка.

При капче или HTTP 403/429 парсер сам делает паузу (1, 2, 4… до 30 мин) и один раз предупреждает в Telegram.

## Тест без интернета

```bash
python tests/test_offline.py
```

Прогоняет весь цикл на подставных страницах: первый запуск, новое объявление, агентство,
продавец с 7 объявлениями, дубль по тексту, повторный проход.

## Ограничения

- Работа проверена только на подставных данных: из среды разработки Авито недоступен.
  При первом живом запуске включите `-v` и пришлите `parser.log`, если что-то не так.
- «Анти-Агент» основан на признаках со страниц карточки и профиля. Авито не отдаёт тип продавца
  стабильным полем, поэтому возможны ошибки в обе стороны.
- Каждое новое объявление при включённом «Анти-Агенте» стоит 1–2 дополнительных запроса.
- Пользовательское соглашение Авито запрещает автоматический сбор данных. Держите интервалы
  разумными и используйте инструмент для собственной работы.
