# Riel Parser: мониторинг новых объектов Авито для риелторов

Десктоп-приложение и консольная версия. Работает на ПК риелтора через его домашний интернет. Следит за ссылками поиска Авито,
находит новые объявления, отсеивает агентов и дубли, присылает новое в Telegram.

## Приложение с интерфейсом

Окно на pywebview, интерфейс на HTML + Tailwind (`ui/`), внутри тот же мониторинг, что и в консольной версии.

- **Лента объектов**: новые объявления от собственников, отсеянные агенты и дубли, поиск и фильтр по клиенту, счётчики.
- **Клиенты и поиски**: для каждого клиента критерии прямо в приложении (город, что ищем, сделка, комнаты,
  цена, площадь, этаж, этажность, не первый/не последний, район или метро, слова-исключения, только частные)
  или своя ссылка с Авито. Поиск можно временно выключить.
- **Лента** разбита на вкладки по клиентам.
- **Настройки**: Telegram (с кнопкой тестового сообщения), интервал и разброс, «Анти-Агент», куки Авито.
- **Журнал**: что программа делает прямо сейчас.
- Кнопка **Запустить / Остановить** и статус со временем до следующей проверки.

Telegram необязателен: без него объекты видны только в ленте.

### Запуск (Windows)

Нужен только Python 3.10+ (при установке отметьте «Add python.exe to PATH»).
Дважды кликните `start_app.bat`. При первом запуске он сам поставит библиотеки (`httpx`, `curl_cffi`, `pywebview`).
Окну нужен Microsoft Edge WebView2, он уже есть в Windows 10/11.

Сборка в `.exe`: `build_exe.bat` → `dist\RielParser.exe` (окно) и `dist\AvitoParser.exe` (консоль).
`config.json`, `history.db` и `parser.log` создаются рядом с `.exe`.

Пересборка стилей после правки `ui/index.html` или `ui/app.js`:

```bash
npx tailwindcss@3.4.17 -c ui/tailwind.config.js -i ui/src.css -o ui/app.css --minify
```

## Консольная версия

Для тестов и серверов без экрана. Настройки те же, в `config.json`.

- `test.bat`: пробный прогон, один проход без отправки в Telegram, подробный лог.
- `start.bat`: рабочий режим.

```bash
python main.py --once --dry-run -v  # пробный прогон
python main.py --test-telegram      # проверить бота
python main.py                      # рабочий режим
```

## config.json

| Поле | Что это |
|---|---|
| `telegram_bot_token` | токен бота от @BotFather |
| `rieltor_chat_id` | chat id риелтора (узнать: написать боту @userinfobot) |
| `global_check_interval_seconds` | пауза между проверками ссылок, не меньше 10 с (рекомендуется 45–90) |
| `jitter_seconds` | случайный разброс паузы, ± секунд |
| `notify_on_first_run` | `false`: при первом запуске ссылки текущие объявления только запоминаются, приходят лишь новые |
| `avito_cookies` | необязательно: строка Cookie из вашего браузера, если Авито показывает капчу (см. ниже) |
| `anti_agent.enabled` | включить фильтр «Анти-Агент» |
| `anti_agent.max_active_listings` | больше скольких активных объявлений у продавца считать его агентом (по умолчанию 1) |
| `anti_agent.max_closed_listings` | больше скольких завершённых объявлений считать агентом (по умолчанию 0) |
| `anti_agent.skip_if_unknown` | пропускать объявление, если продавца проверить не удалось |
| `targets_to_watch` | список `{client_name, avito_url}`; ссылку копируйте из браузера после настройки фильтров на Авито |

## Как работает

0. В режиме «По критериям» город, категория, сделка, цена и «только частные» уходят в адрес запроса к Авито,
   а комнаты, площадь, этажи, район и слова-исключения проверяются по заголовку и адресу каждого объявления.
1. Ссылка из конфига нормализуется: `m.avito.ru` → `www.avito.ru`, сортировка «по дате», первая страница.
2. Страница грузится через `curl_cffi` с TLS-отпечатком Chrome и куками (сначала заход на главную).
3. Объявления берутся из встроенного в страницу JSON-состояния. Если Авито его уберёт, есть запасной разбор HTML.
4. Новые ID проверяются по `history.db` отдельно для каждого клиента, затем по хешу описания (перевыложенные объявления).
5. «Анти-Агент»: открывается карточка и профиль продавца. Компания/агентство или объявлений больше лимита → пропуск.
   Результат проверки продавца кешируется на 7 дней.
6. Сообщение уходит в Telegram: клиент, заголовок, цена, адрес, 150 символов описания, ссылка.

При капче или HTTP 403/429 парсер сам делает паузу (1, 2, 4… до 30 мин) и один раз предупреждает в Telegram.

## Если Авито блокирует (HTTP 429 / 439 / 403)

Это защита Авито от частых запросов с одного IP. Парсер не падает, а делает паузу.

1. Откройте avito.ru в браузере на этом же ПК. Если есть капча, пройдите её. Подождите 10–30 минут.
2. Увеличьте `global_check_interval_seconds` до 60–120 и уберите лишние ссылки.
3. Если не помогает, передайте парсеру куки браузера: на странице Авито нажмите F12 →
   вкладка Network (Сеть) → обновите страницу → кликните первый запрос `www.avito.ru` →
   Headers → Request Headers → скопируйте значение `Cookie` целиком и вставьте в
   `"avito_cookies": "..."`. Куки живут несколько дней, потом их нужно обновить.

## Тест без интернета

```bash
python tests/test_offline.py
python tests/test_criteria.py
```

Прогоняет весь цикл на подставных страницах: первый запуск, новое объявление, агентство,
продавец с 7 объявлениями, дубль по тексту, повторный проход.

## Ограничения

- Работа проверена только на подставных данных: из среды разработки Авито недоступен.
  При первом живом запуске включите `-v` и пришлите `parser.log`, если что-то не так.
- «Анти-Агент» основан на признаках со страниц карточки и профиля. Авито не отдаёт тип продавца
  стабильным полем, поэтому возможны ошибки в обе стороны.
- Каждое новое объявление при включённом «Анти-Агенте» стоит 1–2 дополнительных запроса.
- Пользовательское соглашение Авито запрещает автоматический сбор данных. Держите интервалы
  разумными и используйте инструмент для собственной работы.
